## wotcher

> Note: I have yet to add the silkscreen, but the components are basically finalized. I gotta sketch it out on paper first

Is a digital raise-to-wake LED watch. It's inspired by various retro-style watches, such as the aptly named retrowatch, the charlie watch, and the decko circuit face watch, as well as other pinterest pictures lol.

It uses a charlieplexing chip (IS) to drive the 7-segment display & all 60 LEDs.
